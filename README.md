# IEEE CNAG Site

This repo contains a Vite + React site.

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run locally:

```bash
npm run dev
```

To create a GitHub repo and push from your machine using the `gh` CLI:

```bash
gh repo create <repo-name> --public --source=. --remote=origin --push --confirm
```

Or manually:

```bash
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

To deploy quickly, use Vercel or Netlify and point it at the GitHub repository.
